# PRAVEEN — Cinematic Portfolio

Static, dependency-light cinematic portfolio for Praveen Kumar K R.

## Files
- `index.html` — page structure and content
- `styles.css` — cinematic responsive design
- `script.js` — canvas atmosphere, cursor, clock and scroll reveals
- `assets/` — place personal images/videos here later

## Run locally

Any static server works. For example:

```bash
python -m http.server 5173
```

Then open `http://localhost:5173`.

## Deploy
Upload the contents of this folder to the public web root of a static host such as Hostinger, GitHub Pages or Netlify.

## Content source
Portfolio content is based on the supplied Praveen Kumar K R resume.
